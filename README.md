## ✨ Features

- **🏆 Horizontal to Vertical Mastery**: Effortlessly convert 16:9 gameplay or cinematic footage into social-ready 9:16 vertical clips.
- **🎥 Multi-Camera System**: Define multiple camera regions to follow different subjects in the same video.
- **⚡ Real-time Dual-Canvas Preview**: Manipulate your crops on the source canvas and see the vertical result instantly on the preview canvas.
- **✂️ Precise Trimming**: Set frame-accurate In and Out points for the perfect export.
- **🚀 GPU Accelerated Export**: Powered by FFmpeg for high-quality, fast video processing.
- **🎨 Premium Interface**: A sleek, dark-themed UI (#1b1b1b) with luxurious gold accents designed for focus and aesthetic pleasure.
- **🔄 Auto-Updates**: Stay up to date with the latest features and fixes automatically.

## 🛠️ Tech Stack

- **Core**: Electron, Node.js
- **Engine**: FFmpeg (fluent-ffmpeg)
- **Frontend**: Vanilla JS, HTML5 Canvas, CSS3
- **Build**: Electron Builder, NSIS

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- Windows OS (Optimized for Windows 10/11)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/playerdude901-design/AurumGold-Clip-editor.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run in development mode**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## ⌨️ Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + O` | Open Video File |
| `Space` | Play / Pause |
| `Ctrl + E` | Export Clip |
